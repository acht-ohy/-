開発コンセプト
    手軽に使用できるダイスを中心としたアナログゲーム支援

実装機能
    dice
        内容：
        使用方法：半角英数字で〇〇D△△か〇〇d△△の形で入力
        捕捉：△△面のダイスを〇〇回振る
        制限：ダイスの回数は一回につき、1000回までのセーフティ
    1dice
        内容：ダイスを一回振ります
        使用方法：半角数字を入力してください。
    cocdice
        内容：クリティカル&ファンブル搭載1d100、基本BCCで追加コマンドでCCを指定可能
        使用方法：CCに変更する場合はCCかccと入力。
    parroting
        内容：オウム返しをします
        使用方法：適当な文字列を入力
    scorched_earth_strategy
        内容：焦土作戦実行！を連投し画面を隠すことで、不適切なコンテンツの直視から回避する。
    bot_ver
        botの詳細情報、更新内容を確認できます。

実装予定機能
    汎用dicebot （一部実装済み）
        そのまま数字を入力すると一回その数字のサイコロを振る
        OOdXXの形で入力
        +OOの形で足し引き可能
    HELP
        コマンド一覧
    ERROR
        エラー一覧
    辞書機能
        OO
        と入力するとXXXXXXXXXXXXの部分を閲覧可能
    辞書登録機能
        OO:XXXXXXXXXで登録可能
        OO:コマンドxyと入力すると削除可能
        OO:コマンドryと入力すると編集可能
    辞書禁止ワード設定機能
